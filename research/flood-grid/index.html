Flood-grid study: code and complete results

Reproduce the IEEE 123-node feeder comparison using the original source, flood raster, native feeder files and pinned environment. The published data retain all 360 scenarios and 11,880 AC power-flow solves, including infeasible cases.

Direct downloads

  • Three-page IEEE-format paper (PDF) and paper source and figures (ZIP).
  • Complete reproduction package (ZIP): code, inputs, results, environment and instructions.
  • Complete result data (XZ-compressed JSON): 400,692,377 bytes after decompression.
  • Original simulation source and report generator.
  • Compact results summary and original experiment manifest.
  • Exact Python package versions, Nix development environment, and complete execution instructions.
  • All artifact sizes and SHA-256 hashes and input provenance and upstream terms.

Verify the downloaded package

unzip reproducibility.zip
cd flood-grid-reproducibility
python3 verify_artifacts.py
python3 check_results.py

The first checker verifies every file and the original uncompressed result hash. The second recomputes all 288 aggregate values and counts from the retained solves, and verifies the worked backup-overload example. Neither checker runs a new power-flow simulation.

Run the original experiment

uv venv --python 3.13.14 .venv
uv pip install --python .venv/bin/python -r requirements-lock.txt
.venv/bin/python run_synthetic_flood_grid_resilience.py
.venv/bin/python generate_synthetic_resilience_note.py

On NixOS, enter the included nix-shell first. The README covers runtime libraries and the separate Rainelle public-facility sampling analysis. New simulation output is written separately from the published reference data.

Native inputs

  • Original USGS Rainelle depth raster.
  • IEEE 123 feeder: master, line codes, loads, regulators, and upstream license.
